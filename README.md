# DevOps-спринт: подготовка к стажировке (3–19 октября 2026)

Отдельная дорожка от основного 84-дневного плана в `~/ai-roadmap`. Основной план **не тронут**:
он стоит на дне 17 с серией 20 дней и включится обратно 19 октября автоматически.

## Что это

16 дней × 150 минут (60 автоматизация на Python + 60 инфраструктура/DevOps + 30 конспект и разбор).
Цель — верхнеуровнево закрыть карту компетенций стажировки DevOps и собрать один сквозной артефакт:
сервис, который проходит путь **коммит → CI → образ → деплой в k3s → мониторинг → алерт**.

Программа: `PLAN-DEVOPS-16.md` (человекочитаемо) и `plan.json` (машинночитаемо, тот же источник).
Правила: `build_plan.py` — источник правды по заданиям; `gen_doc.py` рендерит `PLAN-DEVOPS-16.md`;
правки в задания — только в `build_plan.py` + пересборка, прогресс при этом сохраняется.

## Команды

    python3 today.py brief      # задание дня (утро)
    python3 today.py ping       # короткое напоминание (вечер)
    python3 today.py check      # проверка по коммитам: зачесть день или напомнить
    python3 today.py drill      # упражнение дня с эталоном (сверять после своей попытки)
    python3 today.py status     # день, серия, история
    python3 today.py mini       # спасательный день: 15 минут, день не продвигается
    python3 today.py finish     # итог спринта и порядок возврата к основному плану

Зачёт — **коммит с сегодняшней датой** в этом репозитории. Служебные коммиты с префиксом `system:`
не считаются: это правки тренера (движок, план, лаборатории).

Подсказка: пересобрать план из исходника — `python3 build_plan.py && python3 gen_doc.py`.

* 19 октября движок сам переключится на `~/ai-roadmap` (день 17: аннотации типов и mypy + реестр образов).
* Серия и рекорд переносятся из спринта в основной прогресс один раз (метка `.merged`).
* Незакрытые дни спринта не догоняются: тема остаётся доступной — `python3 ~/devops-sprint/today.py brief`
  возвращает карточку дня спринта, `python3 ~/devops-sprint/today.py drill N` — упражнение дня N.
