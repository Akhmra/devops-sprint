# Лаборатория дня 1 — devcheck: инвентарь сервера

Время: ~60 минут на код + 60 минут на инфраструктурную часть (репозиторий, GitHub, карта компетенций).

## Задача одной фразой

Написать утилиту `tools/devcheck.py`, которая смотрит на эту ВМ и печатает, всё ли в норме:
загрузку CPU, занятую память, занятый диск — и выходит с кодом 1, если что-то превышает порог.

## Шаг 1. Посмотреть, откуда брать данные (10 минут)

Набери эти команды и посмотри вывод — всё, что нужно скрипту, лежит в файлах `/proc` и в стандартной библиотеке:

    cat /proc/loadavg
    head -3 /proc/meminfo
    nproc
    df -h /
    uptime

Что ты увидишь на этой ВМ (снято тренером 02.10.2026):

    $ cat /proc/loadavg
    0.42 0.38 0.20 1/475 1647982
    $ head -3 /proc/meminfo
    MemTotal:        4013472 kB
    MemFree:          148936 kB
    MemAvailable:    1569292 kB
    $ nproc
    2
    $ df -h / | tail -1
    /dev/mapper/debian11--vg-root   14G  7.7G  5.1G  61% /
    $ uptime
     22:28:08 up 23 days, 25 min,  3 users,  load average: 0.42, 0.38, 0.20

Как это читать:

* в `/proc/loadavg` три числа — средняя загрузка за 1, 5 и 15 минут; делить на `nproc` (2), чтобы получить «проценты занятости CPU»;
* в `/proc/meminfo` первая строка — вся память, `MemAvailable` — сколько реально можно отдать процессам: процент считать по ним, а не по `MemFree`;
* диск удобнее не парсить, а спросить у Python: `shutil.disk_usage('/')` возвращает `(total, used, free)` в байтах.

Проверь сам, что механизм понятен:

    python3 -c "import shutil; t,u,f = shutil.disk_usage('/'); print(round(u*100.0/t, 1))"
    # 57.5

## Шаг 2. Написать утилиту (40 минут)

Создай папку и файл:

    cd ~/devops-sprint
    mkdir -p tools
    nano tools/devcheck.py     # сохранить: Ctrl+O, Enter; выйти: Ctrl+X

Требования:

1. Запуск: `python3 tools/devcheck.py` — печатает три строки человеческим языком.
2. Ключ `--json` — печатает один JSON-объект вместо текста.
3. Ключ `--threshold N` (по умолчанию 90) — порог в процентах.
4. Если загрузка CPU, память или диск превышают порог — скрипт выходит с кодом **1**, иначе 0.
   Проверить код возврата: `python3 tools/devcheck.py; echo $?`
5. Реализация — только стандартная библиотека (никаких `pip install`): `argparse`, `json`, `shutil`, чтение `/proc`.

Что означает «готово»: скрипт запускается и печатает значения этой ВМ. Пример, как это должно выглядеть:

    $ python3 tools/devcheck.py
    CPU: 21.0% (load 0.42 из 2 ядер)
    Память: 38.3% (занято 1500 МБ из 3919)
    Диск /: 57.5% (свободно 5.1 ГБ)
    Итог: ok

    $ python3 tools/devcheck.py --json
    {"cpu_pct": 21.0, "mem_pct": 38.3, "disk_pct": 57.5, "ok": true}

## Если застрял

* `ModuleNotFoundError: No module named 'shutil'` — так не бывает; скорее файл назван `shutil.py`
  или в папке лежит другой ваш файл с таким именем. Уберите это имя.
* `ZeroDivisionError` при расчёте процента — делить нужно на `total`, а не на `used`.
* «Скрипт ничего не печатает» — код в функциях не вызывается: нужен блок
  `if __name__ == "__main__": main()`.
* `bash: python3: команда не найдена` — вы в другом окружении: используйте `/usr/bin/python3`
  (в системе Python 3.9.2 — синтаксис вида `int | None` и `match` здесь НЕ работает).
* `error: unknown switch 'b'` у `git init -b` — старый git: сделать `git init && git branch -M main`.
